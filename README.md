# Projeto _**'Olivia's Archive'**_ site.

Pensado inicialmente para ser apenas um site simples desenvolvido durante meu curso de Git e GitHub, este projeto acabou se tornando uma forma de praticar desenvolvimento web, versionamento e o uso da plataforma enquanto criava algo inspirado em temas que gosto.

Usando tudo o que venho aprendendo, a proposta do site é simples:

* Reunir referências de design que acho interessantes, como pixel art, sites dos anos 2000 e blogs clássicos;
* Simular um blog de reviews de entretenimento, com foco em séries, filmes e outras obras;
* Ter um toque de diário pessoal, registrando avaliações e opiniões;
* Utilizar a personagem **Olivia** como a "dona" do site, mesmo sendo um projeto criado por mim;
* Ser um projeto leve, divertido de desenvolver e que evolua conforme aprendo novas tecnologias.

## Objetivo

- Reunir inspirações de design;
- Criar um blog fictício de reviews;
- Praticar HTML, CSS, JavaScript, Git e GitHub;
- Desenvolver um projeto que evolua conforme meus estudos.

## Tecnologias

- HTML5.
- CSS3.
- JavaScript.
